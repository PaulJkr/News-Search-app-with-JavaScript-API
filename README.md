A clean and responsive **news search web app** built using **vanilla JavaScript** and the [NewsAPI](https://newsapi.org/).  
Users can instantly search and view the latest articles from various sources across the globe 🌍.

---

## ✨ Features

- 🔍 **Live Search** – Enter keywords and get instant news results
- 🗞️ **Headline Cards** – Displays title, source, image, and short description
- 🌐 **Responsive Design** – Works well on desktop and mobile
- 📅 **Published Dates** – View article timestamps
- 🔗 **External Links** – Click to read full articles on the original site


## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **API**: [NewsAPI.org](https://newsapi.org/)
- **UX**: Responsive layout with cards and grid/flexbox

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PaulJkr/News-Search-app-with-JavaScript-API.git
cd News-Search-app-with-JavaScript-API
```
### 2. Open index.html in Your Browser

```bash
You can directly open the app by double-clicking index.html or use Live Server if you have VSCode.
```

# 🔐 API Key Setup
Go to https://newsapi.org/

Sign up and get a free API key

In your code, replace this placeholder:
```bash
const apiKey = "YOUR_API_KEY_HERE";
```
# 🎮 Usage
Type a search term like climate, technology, or sports.

Press enter or click the search button.

Browse top articles pulled from the NewsAPI.
